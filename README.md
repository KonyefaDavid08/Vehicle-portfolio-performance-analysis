# Vehicle-portfolio-performance-analysis
Power BI dashboard analyzing portfolio payments, outstanding balances, frozen assets, location performance, and worst-performing assets.
The objective of this project is to analyze portfolio performance and identify assets and locations requiring management attention.

The analysis focuses on:
- Frozen/offline assets
- Low payment performance
- Outstanding balances
- Locations with a high concentration of problem assets

## 2. Data Preparation

The dataset was cleaned and prepared for analysis.

Key preparation steps included:
- Reviewing asset records
- Checking payment information
- Calculating payment rates
- Calculating outstanding balances
- Grouping assets by location
- Creating payment-rate bands
- Identifying the lowest-performing assets

## 3. KPIs

The dashboard tracks:
- Total Assets
- Total Payment
- Payment Rate
- Outstanding Balance
